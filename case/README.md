# 3D-printed case

> **Work in progress.** This is a first mockup, made to test the fit of the components rather than to be a finished case. I printed it in PLA, and it still needs several changes before it is nice to look at and comfortable to hold.

The case is a two-part shell (front and back) that holds the **Freenove ESP32-S3 2.8" display**, the LiPo battery and the Qi wireless charging receiver.

## Files

The **STEP** files of the front and back shell are in this folder. You can open and modify them in any CAD program (Fusion, FreeCAD, Onshape…) or import them directly into most slicers.

## What's inside

- Freenove ESP32-S3 Display 2.8" (PCB 50 × 86 mm), fixed with self-tapping screws
- LiPo battery 102050 (1000 mAh), in an extension next to the screen
- Qi wireless charging receiver with USB-C output, behind the board

## Next steps
